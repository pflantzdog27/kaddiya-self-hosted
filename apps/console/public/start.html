02

Connect ServiceNow

Create one OAuth record on your instance. No application or plugin installation is needed for this connection. Use a developer or test instance to get started.

  1. Open Machine Identity Console → Inbound integrations → New integration → OAuth - Authorization code grant. In classic navigation: System OAuth → Application Registry → New → Create an OAuth API endpoint for external clients.
  2. Set the name and provider name to Kaddiya. Paste the redirect URL below. Leave Public client unchecked and Active checked, then save.
  3. Copy the generated client ID and secret into this form.
Redirect URL · paste this into the record
The secret is encrypted in your deployment’s database and is never returned to the browser.
You will be sent to your instance's own login page.

What happens when you sign in

Sign in on ServiceNow as an administrator. Kaddiya checks the OAuth record and redirect URL, then makes you the workspace owner. Next, you’ll add and test your model connections. Other members need your approval before joining.
