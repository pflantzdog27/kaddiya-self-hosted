# containersplitvariable-api

Tags: ContainerSplitVariable, variable, service catalog, container, layout

ContainerSplitVariable

A CatalogItem variable for a container split field (used for creating columns within a container).


Signature

```typescript fluent
ContainerSplitVariable(config)
```


Parameters

config

ContainerSplitVariableType

Configuration for the container split variable including:

Properties:

• active (optional): boolean
  Indicates whether the variable is active

• disableInitialSlotFill (optional): boolean
  Disable automatic slot fill based on user contex

• order (optional): number
  Order in which the variable appears
